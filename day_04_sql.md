# 🗄️ Day 4: SQL

**Date:** 2026-09-14 | **Time:** 2-3 hours | **Focus:** SQL querying, joins, aggregations, and advanced concepts

## 🎯 Learning Objectives
By the end of today, you should be able to:
- Write basic SQL queries (SELECT, WHERE, GROUP BY, ORDER BY)
- Perform various types of JOINs (INNER, LEFT, RIGHT, FULL, SELF)
- Use subqueries and common table expressions (CTEs)
- Apply window functions for advanced analytics
- Handle data modification (INSERT, UPDATE, DELETE)
- Understand indexes, transactions, and performance optimization
- Work with string functions, date/time functions, and case statements

## 📚 Key Topics to Cover

### 1. SQL Basics Review (20 min)
- SELECT statement: columns, DISTINCT, WHERE, ORDER BY, LIMIT
- Data types: numeric, string, date/time, boolean
- Basic filtering: comparison operators, LIKE, IN, BETWEEN, IS NULL
- Aggregation functions: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING clauses

### 2. Joins & Relationships (40 min)
- INNER JOIN: matching records from both tables
- LEFT JOIN / RIGHT JOIN: preserving unmatched records from one table
- FULL OUTER JOIN: preserving unmatched records from both tables
- SELF JOIN: joining a table to itself
- CROSS JOIN: Cartesian product
- Joining on multiple conditions
- Handling NULLs in joins
- Natural joins vs explicit joins

### 3. Subqueries & CTEs (30 min)
- Scalar subqueries: single value results
- Column subqueries: multiple rows, single column
- Row subqueries: multiple columns, single row
- Table subqueries: multiple rows and columns (derived tables)
- Common Table Expressions (CTEs): WITH clause
- Recursive CTEs for hierarchical data
- Correlated vs non-correlated subqueries
- EXISTS and NOT EXISTS operators

### 4. Window Functions (35 min)
- OVER clause: PARTITION BY, ORDER BY, FRAME
- Ranking functions: ROW_NUMBER, RANK, DENSE_RANK, NTILE
- Aggregate window functions: SUM, AVG, COUNT, MIN, MAX over window
- Analytic functions: LAG, LEAD, FIRST_VALUE, LAST_VALUE, NTH_VALUE
- Percentile functions: PERCENT_RANK, CUME_DIST
- Practical use cases: running totals, moving averages, ranking within groups

### 5. Data Modification & Definition (25 min)
- INSERT: single row, multiple rows, INSERT ... SELECT
- UPDATE: modifying existing data, JOIN in UPDATE
- DELETE: removing data, TRUNCATE vs DELETE
- CREATE TABLE: data types, constraints (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK)
- ALTER TABLE: adding/dropping columns, modifying constraints
- DROP TABLE
- Transactions: BEGIN, COMMIT, ROLLBACK, SAVEPOINT
- Isolation levels and concurrency control

### 6. Advanced Topics (20 min)
- String functions: CONCAT, SUBSTRING, TRIM, UPPER/LOWER, REPLACE, REGEXP
- Date/time functions: NOW, DATE_ADD, DATE_SUB, DATEDIFF, EXTRACT, FORMAT
- CASE expressions: simple and searched CASE
- COALESCE and NULLIF for handling NULLs
- Views: creating, using, updating
- Indexes: types (B-tree, hash, bitmap), when to use, EXPLAIN plan
- Stored procedures and functions (basic understanding)

## 🔧 Practice Exercises

### Exercise 1: Basic Queries & Aggregations (25 min)
**Scenario:** You have access to an e-commerce database with tables: `users`, `orders`, `order_items`, `products`.

**Tasks:**
1. Find the total number of users
2. List all orders placed in the last 30 days
3. Calculate the average order value (total revenue / number of orders)
4. Find the top 5 most expensive products
5. Count the number of orders per user, sorted by count descending
6. Find users who have never placed an order
7. Calculate monthly revenue for the last 6 months

### Exercise 2: Joins Practice (30 min)
**Scenario:** Analyze customer behavior and product performance.

**Tasks:**
1. Get a list of all orders with user details (user name, email) and product details (product name, price)
2. Find products that have never been ordered
3. Calculate the total revenue generated by each product category
4. Find the top 3 users by total spending
5. For each order, show the order date, user name, and the number of items in the order
6. Find users who placed orders in both January and February of this year
7. Calculate the average time between a user's first and last order

### Exercise 3: Subqueries & CTEs (25 min)
**Scenario:** Perform advanced analytics on sales data.

**Tasks:**
1. Find the second highest salary in the employees table (without using LIMIT)
2. List all products that are priced above the average product price
3. For each category, find the most expensive product
4. Calculate the running total of daily sales using a CTE
5. Find customers who have spent more than the average customer
6. Identify orders where the total amount is greater than the average order amount for that month
7. Use a recursive CTE to find all subcategories under a given category (if hierarchy exists)

### Exercise 4: Window Functions (30 min)
**Scenario:** Analyze trends and performance metrics.

**Tasks:**
1. For each user, show their orders in chronological order with a running total of their spending
2. Rank products within each category by revenue (use RANK and DENSE_RANK)
3. Calculate the month-over-month growth rate in total revenue
4. Find the top 3 selling products each month for the last 6 months
5. Calculate a 7-day moving average of daily active users
6. Identify streaks: consecutive days where a user placed an order
7. For each order, show the percentage of total daily revenue it represents

### Exercise 5: Data Modification & Optimization (20 min)
**Scenario:** Maintain and optimize the database.

**Tasks:**
1. Insert a new product into the products table
2. Update the price of all products in a specific category by increasing it by 10%
3. Delete inactive users (users who haven't placed an order in the last 2 years)
4. Create an index on the frequently queried columns (e.g., order_date, user_id)
5. Write a query to find the execution plan of a complex query (using EXPLAIN)
6. Create a view that shows monthly sales summary
7. Write a transaction that transfers money between two accounts atomically
